# 📚 เอกสารสถาปัตยกรรมข้อมูล (Data Architecture & Provenance)
## โครงการ TTM Smutthan Engine Platform (Hackathon 2026)

> [!CAUTION]
> **ข้อความปฏิเสธความรับผิดชอบ (Data & Clinical Disclaimer):**
> ข้อมูลผู้ป่วย ประวัติการรักษา และการสั่งยาทั้งหมดในโฟลเดอร์ `data/` เป็น **"ข้อมูลสังเคราะห์เพื่อการสาธิต (Synthetic Demonstration Data)"** ทั้งสิ้น ห้ามนำไปอ้างว่าเป็นข้อมูลผู้ป่วยจริง และห้ามนำข้อมูลผู้ป่วยจริงขึ้นสู่ระบบสาธารณะ ข้อมูลสมุนไพรและปฏิกิริยายาได้รับการติดป้าย **"ตัวอย่าง รอเภสัชกร/แพทย์แผนไทยตรวจสอบ"** ระบบนี้พัฒนาขึ้นเพื่อเป็นเครื่องมือสนับสนุนการตัดสินใจทางคลินิก (Clinical Decision Support System: CDSS) มิใช่การวินิจฉัยหรือสั่งยาอัตโนมัติแทนแพทย์แผนไทย

### 1. แหล่งที่มาของข้อมูล (Data Provenance & Official References)

ข้อมูลและมาตรฐานอ้างอิงในโครงการนี้ได้รับการสำรวจและสังเคราะห์จากเอกสารทางการในคลังข้อมูล:
1. **บัญชียาหลักแห่งชาติ (NLEM มีนาคม 2568):** สกัดจากตาราง `media.xlsx` กลุ่มยาแผนปัจจุบัน 1,361 รายการ นำมาจัดทำเป็นยา Master 12 รายการสำหรับเคส C01-C10 พร้อมข้อมูลความแรง, รูปแบบยา และประเภทย่อย (ก, ข, ค)
2. **คู่มือรหัสยาแผนไทย 24 หลัก สำหรับหน่วยบริการสาธารณสุขของรัฐ (พ.ศ. 2568):** สถาบันการแพทย์แผนไทย กรมการแพทย์แผนไทยและการแพทย์ทางเลือก กระทรวงสาธารณสุข สำหรับโครงสร้างรหัสยา 24 หลัก และรหัสกำกับมาตรฐาน TTMTID
3. **คู่มือเปรียบเทียบโรคและอาการและหัตถการด้านการแพทย์แผนไทย (พ.ศ. 2568):** กรมการแพทย์แผนไทยฯ สำหรับการจับคู่รหัสวินิจฉัย ICD-10-TM (รหัส U) กับ ICD-10 สากล และรหัสหัตถการมาตรฐาน (9007710, 9007720, 9007730 ฯลฯ)
4. **แนวทางการรักษาอาการเจ็บป่วยด้วยยาสมุนไพรในระบบบริการปฐมภูมิ (ฉบับ พ.ศ. 2568):** สถาบันการแพทย์แผนไทย สำหรับขนาดยามาตรฐาน ผู้ใหญ่/เด็ก ข้อบ่งใช้ ข้อห้าม และข้อควรระวัง
5. **คู่มือคำอธิบายศัพท์เทคนิค (Glossary):** คณะผู้จัดงาน Hackathon สำหรับนิยาม Prototype (ระดับ 1.3 Functional Prototype, ระดับ 1.4 MVP-ready)

### 4. การเชื่อมต่อ 43 แฟ้ม และแผนสลับเป็นข้อมูลจริงผ่าน Adapter Layer

ระบบออกแบบให้มี **Adapter Pattern** ในโค้ด frontend (`/src/adapters/`):
- `MockAdapter`: อ่านข้อมูลจากไฟล์ JSON สังเคราะห์ สำหรับการรันบน GitHub Pages แบบไร้เซิร์ฟเวอร์
- `FortyThreeFilesAdapter`: สามารถอ่านไฟล์ CSV ของ 43 แฟ้มจากโรงพยาบาลผ่าน Web File API หรือ local dropzone โดยแมปชื่อฟิลด์ตาม `config/mapping-43folders.json`
- `HisRestAdapter / FhirAdapter`: สำหรับเชื่อมต่อ HIS จริง (HOSxP, EHP, SSB, Himpro) ผ่าน OpenAPI Specification (`openapi.yaml`) ในอนาคต

> [!NOTE]
> **การตรวจสอบ Data Dictionary ล่าสุด:**
> ชื่อฟิลด์ รหัสสถานพยาบาล และประเภทการลงรหัสใน `config/mapping-43folders.json` ต้องได้รับการตรวจสอบยืนยันกับ Data Dictionary ของศูนย์เทคโนโลยีสารสนเทศและการสื่อสาร สำนักงานปลัดกระทรวงสาธารณสุข ก่อนการเชื่อมต่อระบบจริงในโรงพยาบาล

### 5. สคริปต์ความปลอดภัยและการนิรนามข้อมูล (PII Scanner & De-identification)

1. **`scripts/check-pii.py`:** สแกนข้อมูลในโครงการเพื่อป้องกันเลขบัตรประชาชน 13 หลัก, เบอร์โทรศัพท์ และอีเมลจริงหลุดขึ้น Git
   ```bash
   python scripts/check-pii.py
   ```
2. **`scripts/deidentify.py`:** เครื่องมือนิรนามข้อมูลคนไข้จริงจาก HIS (Pseudonymization & k-anonymity) ให้พร้อมก่อนนำเข้าโครงการทดสอบ
   ```bash
   python scripts/deidentify.py
   ```
