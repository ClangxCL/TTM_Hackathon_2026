## 1. กรอบแนวคิดการประเมินทางเศรษฐศาสตร์สาธารณสุข (Health Economics Framework)

การประเมินความคุ้มค่าของการรักษาด้วยการแพทย์แผนไทย (TTM) เมื่อเทียบหรือใช้ร่วมกับการแพทย์แผนปัจจุบัน สามารถมองได้ใน 2 มิติหลัก:

```
                          ┌──────────────────────────┐
                          │   กรอบเศรษฐศาสตร์สาธารณสุข  │
                          └─────────────┬────────────┘
                                        │
                 ┌──────────────────────┴──────────────────────┐
                 ▼                                             ▼
┌─────────────────────────────────┐           ┌─────────────────────────────────┐
│ Cost-Effectiveness Analysis     │           │ Cost-Utility Analysis           │
│ (CEA: การวิเคราะห์ต้นทุน-ประสิทธิผล)│           │ (CUA: การวิเคราะห์ต้นทุน-อรรถประโยชน์)│
├─────────────────────────────────┤           ├─────────────────────────────────┤
│ • ต้นทุนต่อการลดระดับความปวด    │           │ • ต้นทุนต่อปีสุขภาวะ (Cost/QALY)│
│   (Cost per 1-point Pain drop)  │           │ • คุณภาพชีวิตผู้ป่วยโรคเรื้อรัง │
│ • การลดการใช้ยาแก้ปวดกลุ่ม      │           │ • ผลตอบแทนความคุ้มค่าภายใต้     │
│   NSAIDs / Opioids              │           │   เกณฑ์ความเต็มใจจ่าย (WTP)     │
└─────────────────────────────────┘           └─────────────────────────────────┘
```

## 2. โครงสร้างต้นทุนต่อรอบการรักษา (Cost per Episode Breakdown)

ต้นทุนรวมต่อการรับบริการ 1 ครั้ง (Encounter Cost) ประกอบด้วย 3 องค์ประกอบหลัก:

$$\text{Total Encounter Cost} = C_{\text{procedure}} + C_{\text{herb}} + C_{\text{conventional}}$$

| องค์ประกอบต้นทุน (Cost Component) | รายละเอียดและอัตรามาตรฐาน | ประโยชน์ต่อระบบสุขภาพ |
|---|---|---|
| **1. ค่าหัตถการแผนไทย ($C_{\text{procedure}}$)** | • นวดไทยเพื่อการบำบัด (9007710): 250 บาท<br/>• ประคบสมุนไพร (9007712): 150 บาท<br/>• อบไอน้ำสมุนไพร: 100 บาท | ฟื้นฟูกล้ามเนื้อและเส้นเอ็นโดยตรง ลดการเกิดพังผืด ไม่เกิดพิษสะสมในร่างกาย |
| **2. ค่ายาสมุนไพร ($C_{\text{herb}}$)** | • ยาแคปซูลขมิ้นชัน: 2.50 บาท/แคปซูล<br/>• ยาแคปซูลขิง: 2.50 บาท/แคปซูล<br/>• ครีมไพล: 35 บาท/หลอด | ผลิตจากวัตถุดิบในประเทศ สนับสนุนเศรษฐกิจฐานรากและลดการนำเข้ายาต่างประเทศ |
| **3. ค่ายาแผนปัจจุบัน ($C_{\text{conventional}}$)** | • ยาลดความดัน, ยาเบาหวาน, ยาต้านการแข็งตัวของเลือด | รักษาระดับการควบคุมโรคเรื้อรังหลัก (NCDs) ให้คงที่ |

## 3. ผลการวิเคราะห์ข้อมูลประชากรจำลอง (Synthetic Cohort Analysis: C01–C10)

จากการประมวลผลข้อมูลการรับบริการย้อนหลัง 6–12 เดือนของกลุ่มเคสตัวอย่าง 10 เคส (C01–C10) รวม 51 ครั้งการรักษา พบข้อมูลเชิงเศรษฐศาสตร์ดังนี้:

| ตัวชี้วัดทางเศรษฐศาสตร์ (Economic Metric) | ค่าที่คำนวณได้จริงในระบบ | การแปลผลทางนโยบายสุขภาพ |
|---|:---:|---|
| **ต้นทุนเฉลี่ยต่อครั้ง (Avg. Cost per Visit)** | **386 บาท / ครั้ง** | ต้นทุนอยู่ในเกณฑ์ประหยัดมาก เมื่อเทียบกับการรักษาในแผนกผู้ป่วยนอก รพช. (เฉลี่ย 850-1,200 บาท) |
| **สัดส่วนค่ายาแผนไทยต่อยาแผนปัจจุบัน** | **0.42 : 1.00** | การใช้ยาสมุนไพรมีต้นทุนต่ำกว่ายาเคมีสังเคราะห์มากกว่าเท่าตัว |
| **รหัสโรคกลุ่ม U ที่พบบ่อยที่สุด** | **U55.22 (โรคลมจับโปงแห้งเข่า)** | สอดคล้องกับระบาดวิทยาของสังคมสูงวัยในชนบทไทย มีต้นทุนเฉลี่ย 410 บาท/ครั้ง |
| **รหัสโรคอันดับสอง** | **U54.1 (โรคลมปลายปัตฆาตสัญญาณ 4 หลัง)** | ปวดหลังส่วนล่างเรื้อรัง (Office Syndrome/แรงงาน) มีต้นทุนเฉลี่ย 390 บาท/ครั้ง |

## 4. มูลค่าทางเศรษฐศาสตร์ของการป้องกันอันตรกิริยายา (Economic Value of HDI Prevention)

การมี **Centralized HDI Engine** ช่วยป้องกันภาวะแทรกซ้อนรุนแรง ซึ่งมีมูลค่าทางเศรษฐศาสตร์มหาศาลต่อระบบประกันสุขภาพถ้วนหน้า (UCS):

1. **การป้องกันเลือดออกในทางเดินอาหาร (Warfarin + ขมิ้นชัน / ขิง):**
   - ค่ารักษาเฉลี่ยของการ Admit ผู้ป่วย Upper GI Bleeding ใน รพ.ทั่วไป: **28,000 - 45,000 บาท/ครั้ง**
   - การเตือนและป้องกันเคส C02 เพียง 1 เคส ช่วยประหยัดงบประมาณกองทุน UC ได้มากกว่าค่าติดตั้งระบบทั้ง รพ.สต.
2. **การป้องกันพิษจาก Digoxin (Digoxin + ชะเอมเทศ):**
   - ค่ารักษาภาวะหัวใจเต้นผิดจังหวะรุนแรงในหอผู้ป่วยวิกฤต (ICU): **60,000 - 120,000 บาท/ครั้ง**
   - หลีกเลี่ยงอัตราการเสียชีวิตเฉียบพลันในผู้สูงอายุ
3. **การทดแทนยาแก้ปวด NSAIDs ด้วยการนวดประคบและครีมไพล:**
   - ลดอัตราการเกิดโรคกระเพาะอาหารอักเสบและไตวายเฉียบพลันจากยา (NSAID-induced Nephropathy)
