## 2. รายละเอียดข้อมูลนำเข้า (Input Specifications)

### 2.1 ข้อมูลประชากรและสรีรวิทยา (Patient Demographics & Vitals)
- **HN (Hospital Number):** รหัสประจำตัวผู้ป่วย เช่น `HN-2568001`
- **อายุ (Age):** จำแนกเข้าสู่ 3 ช่วงวัย (อายุสมุฏฐาน):
  - *ปฐมวัย (0-16 ปี):* อาโปธาตุ (เสมหะสมุฏฐาน)
  - *มัชฌิมวัย (16-32 ปี):* เตโชธาตุ (ปิตตะสมุฏฐาน)
  - *ปัจฉิมวัย (32 ปีขึ้นไป):* วาโยธาตุ (วาตะสมุฏฐาน)
- **สัญญาณชีพ (Vitals):**
  - อุณหภูมิกาย (`btemp`): เกณฑ์ไข้ต่ำ (>= 37.3°C), ไข้สูง (>= 37.8°C) กระตุ้นเตโชธาตุ
  - ความดันโลหิต (`sbp` / `dbp`): >= 140/90 mmHg กระตุ้นวาโยธาตุและเตโชธาตุ
  - ชีพจร (`pr`): >= 95 bpm กระตุ้นหทัยวาตะ
  - อัตราการหายใจ (`rr`), น้ำหนัก (`weight_kg`), ส่วนสูง (`height_cm`), ดัชนีมวลกาย (`bmi`)

### 2.2 สภาวะแวดล้อมและช่วงเวลา (Ambient & Temporal Context)
- **พิกัดและสถานที่:** ละติจูด, ลองจิจูด, ชื่อสถานพยาบาล (เช่น รพ.สต.บางกระทุ่ม จ.พิษณุโลก)
- **อุณหภูมิภายนอก (°C):** ดึงผ่าน Open-Meteo REST API
  - >= 35.0°C: ความร้อนจัด กระตุ้นเตโชธาตุ (+18) ลดอาโปธาตุ (-10)
  - <= 22.0°C: อากาศเย็น กระตุ้นอาโปธาตุ (+15) วาโยธาตุ (+5) ลดเตโชธาตุ (-10)
- **ความชื้นสัมพัทธ์ (%):** >= 80% กระตุ้นอาโปธาตุ (+14), <= 45% อากาศแห้ง ดึงความชื้นออก
- **กาลสมุฏฐาน (Kala Period):** จำแนกตามเวลาที่ทำการตรวจ:
  - 06:00 - 10:00 น. / 18:00 - 22:00 น. = เสมหะกาล (อาโปธาตุ +10)
  - 10:00 - 14:00 น. = ปิตตะกาล (เตโชธาตุ +12)
  - 14:00 - 18:00 น. / 22:00 - 06:00 น. = วาตะกาล (วาโยธาตุ +12)

### 2.3 ประวัติยาแผนปัจจุบันที่กำลังใช้อยู่ (Active Conventional Medications)
- ดึงจากระบบ HIS ผ่าน Adapter:
  - รหัสยา, Generic Name, Strength, ขนาดยาต่อครั้ง, ความถี่, เวลาที่รับประทาน, จำนวนวันที่ได้รับ

## 3. รายละเอียดการประมวลผล (Processing Specifications)

### 3.1 การคำนวณสมุฏฐานธาตุ (Smutthan Calculation Engine)
- ค่าเริ่มต้น (Baseline): แต่ละธาตุเริ่มที่ 25.0 คะแนน (ผลรวม 100 คะแนน)
- คำนวณ Delta Score แบบสะสมตามลำดับปัจจัย:
  1. กฎอุตุสมุฏฐาน (สภาพอากาศภายนอก)
  2. กฎกาลสมุฏฐาน (ช่วงเวลาตรวจ)
  3. กฎอายุสมุฏฐาน (ช่วงวัยผู้ป่วย)
  4. กฎสัญญาณชีพ (ไข้, ความดัน, ชีพจร)
  5. กฎอาการสำคัญ (ปวดเมื่อยเส้นเอ็น, ทางเดินอาหาร, ทางเดินหายใจ, ความร้อนภายใน)
- ปรับสเกลให้อยู่ในช่วง 10 - 100 คะแนน
- จำแนกสถานะ:
  - คะแนนสูงสุด >= 65: **กำเริบ (Aggravated)**
  - คะแนนสูงสุด <= 35: **หย่อน (Deficient)**
  - 36 - 64: **สมดุล (Normal)**

### 3.2 การตรวจจับอันตรกิริยา (Herb-Drug Interaction Matcher)
- อัลกอริทึมจับคู่ `ActiveMedication.generic_name` และ `SelectedHerb.thai_name` / `drug_code_24`
- ประเมินผลกระทบ:
  - **ความเสี่ยงสูง (HIGH):** เช่น Warfarin + ขมิ้นชัน (เลือดออกรุนแรง), Digoxin + ชะเอมเทศ (หัวใจเต้นผิดจังหวะ)
  - **ความเสี่ยงปานกลาง (MODERATE):** เช่น Amlodipine + ชะเอมเทศ (ความดันโลหิตสูงขึ้น), Metformin + มะระขี้นก (น้ำตาลต่ำ)
  - **ความเสี่ยงต่ำ (LOW):** เช่น Cetirizine + ฟ้าทะลายโจร (ง่วงซึมเล็กน้อย)

## 4. รายละเอียดผลลัพธ์ที่ส่งออก (Output Specifications)

### 4.1 หน้าจอแสดงผลทางคลินิก (Clinical UI Dashboard)
- **Element Balance Radar Chart:** แผนภูมิใยแมงมุมแสดงคะแนน 4 ธาตุ เปรียบเทียบกับเกณฑ์สมดุล
- **Explainable Reasons List:** ตารางแจกแจงสาเหตุ ปัจจัยนำเข้า และคะแนนผลกระทบ (+/-)
- **Clinical Prescription Sheet:** ใบสั่งยาที่มีรายละเอียดตัวยา, รหัส 24 หลัก, วิธีใช้, รสยา, ข้อควรระวัง, และคำเตือนอันตรกิริยา
- **Decision Support Disclaimer:** ระบุชัดเจนว่าเป็นระบบสนับสนุนการตัดสินใจ มิใช่การวินิจฉัยแทนแพทย์

### 4.2 ข้อมูลมาตรฐานส่งออก (Standard Export Formats)
- **MOPH 43-Folders Schema:**
  - แฟ้ม `DRUG_OPD`: รหัสยา 24 หลัก, ปริมาณ, วิธีใช้, ราคายา
  - แฟ้ม `DIAGNOSIS_OPD`: รหัสโรค ICD-10-TM (กลุ่ม U) และ ICD-10 สากล
  - แฟ้ม `PROCEDURE_OPD`: รหัสหัตถการไทย สนย. (เช่น 9007710 นวดรักษา)
- **HL7 FHIR MedicationRequest JSON:** โครงสร้างมาตรฐานตาม FHIR R4 พร้อม Coding System และ DosageInstruction
